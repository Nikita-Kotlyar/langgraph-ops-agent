# Безопасность

## Поддерживаемые версии

| Версия | Поддержка |
|---|---|
| 0.1.x | да |

## Как сообщить об уязвимости

Не создавай публичный issue для уязвимости. Напиши владельцу репозитория
через GitHub или указанный в профиле контакт. Укажи:

- версию и конфигурацию;
- шаги воспроизведения;
- потенциальное влияние;
- предложение по исправлению, если есть.

## Модель безопасности

- MCP-инструменты работают только с read-only доступом к данным.
- Действия, меняющие резервы, деньги или сроки клиента, требуют approval.
- Все действия фиксируются в `runs/{thread_id}/actions.jsonl`.
- Секреты хранятся в `.env` или секрет-хранилище; `.env` исключён из git.
- В репозитории нет реальных персональных данных и ключей.

## Ограничения контура

- API публикуется через ingress; аутентификация и роли — на уровне gateway.
- MCP-сервер работает в периметре предприятия.
- Для внешнего LLM-провайдера используется корпоративный шлюз с лимитами
  и аудитом запросов.
