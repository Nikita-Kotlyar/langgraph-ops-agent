# Участие в разработке

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/)
- Docker (для проверки compose)
- Доступ к модели через RouterAI, Anthropic или OpenAI-совместимый endpoint

## Подготовка окружения

```bash
uv sync --extra dev
cp .env.example .env
```

В `.env` укажи провайдера, модель и ключ. Секреты не коммитятся.

## Проверки перед PR

```bash
uv run ruff check app tests
uv run pytest -m "not mcp"
uv run pytest
```

Все тесты должны проходить. Для изменений в MCP-сервере обязателен полный
прогон, включая `tests/test_mcp.py`.

## Стиль

- Python 3.12, типизация, `ruff` с настройками из `pyproject.toml`.
- Промпты и документация — на русском языке.
- Новые инструменты MCP оформляются с docstring и тестом.
- Новые действия, меняющие данные или тратящие деньги, обязаны иметь
  `requires_approval=true` и запись в аудит.

## Коммиты

- Один коммит — одна логическая change.
- Сообщение в формате `feat:`, `fix:`, `docs:`, `test:`, `refactor:`.
- Не добавлять в коммиты ключи, `.env`, `runs/` и служебные артефакты.
- Не добавлять соавторство инструментов и генеративного ПО.

## Данные

- В репозитории только обезличенные данные.
- Реальные персональные данные, ключи и внутренние документы не допускаются.
- Эталонные ответы (`data/expected`) используются только для проверки.

## Pull request

В описании укажи:

1. что изменено;
2. как проверено;
3. влияние на API, MCP-инструменты и approval-поток;
4. обновлены ли README и `docs/ARCHITECTURE.md`.
